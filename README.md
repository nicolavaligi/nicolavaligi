# houdinick

Uso l’AI per progettare, scrivere e testare software. Configuro agenti che lavorano con i tuoi documenti, le tue fonti e gli strumenti che usi già. [Sito e contatti](https://www.nicvaligi.com/)

## Strumenti da provare

- **itscrub** — Individua e maschera codici fiscali, partite IVA e altri dati personali italiani in log e file. Funziona in locale con Python, senza dipendenze. [Esempi e installazione](https://github.com/nicolavaligi/italian-pii-scrubber#readme)
- **Claude Sessions to Obsidian** — Esporta le sessioni di Claude Code in note Markdown ricercabili in Obsidian. Il comando `--dry-run` mostra cosa verrebbe esportato. [Avvio rapido](https://github.com/nicolavaligi/claude-sessions-to-obsidian#quick-start)
- **Sitepulse** — Misura un sito, conserva lo storico e confronta le verifiche tra una settimana e l’altra. [Comando di prova](https://github.com/nicolavaligi/sitepulse#quick-start)

## Progetti geospaziali e applicazioni

- **Motore Espropri Italia** — Archivio documentale e cartografico per opere infrastrutturali, atti degli enti, particelle e geometrie. [Repository](https://github.com/nicolavaligi/motore-espropri-italia)
- **SunPro** — Analisi geospaziale per la ricerca di terreni fotovoltaici, con mappa 3D e dossier. [Repository](https://github.com/nicolavaligi/sunpro)
- **Houdinick Data Feeds** — SDK Python ed esempi di integrazione con API per appalti, bonifiche e terreni. [Repository](https://github.com/nicolavaligi/houdinick-data-feeds)
- **Free Your Garage** — Prototipo per lo scambio di ricambi moto. [Repository](https://github.com/nicolavaligi/free-your-garage)
